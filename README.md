# TANKERS-BOT

Telegram-бот для управления командой разработки 2D-танков.
Python 3.10+, aiogram 3, SQLite (`tank_bot.db`), APScheduler.

## Запуск

```bash
pip install -r requirements.txt
python main.py
```

Токен бота — в файле `config.py` (`BOT_TOKEN`). Хостинг: Kerit Cloud, FadeHost или
Render — команда запуска `python main.py`.

## Что умеет

- **Задания**: создание (с нуля или 📑 из шаблона), должность/общие, срок, кто
  может закрывать, публикация в чаты; сдача работ: свободный отчёт, по форме,
  корректировка, ответ на другое задание; текст/фото/файлы.
- **Оценивание**: куратор должности или владелец; оценка 1–10, итог
  (правильно +5, частично +3, неправильно +1, совсем неверно +0, плюс оценка×0.5),
  комментарий с фото, отметка «лучшая работа» (+3), запрос корректировки.
- **Чек-листы**: название, срок, бонус, пункты, назначение (каждому/свободно/
  по одному), проверяющий; выполнение с подтверждением (текст/фото/файл);
  проверка пунктов; баллы 0.5/0.4 за пункт, ложь −10, неверная проверка −7,
  идеальный чек-лист +2 каждому.
- **Наказания**: предупреждение, минус баллы, отчёт за месяц (бот даёт данные
  за 4 недели и сам проверяет итог), поиск информации, своё задание; срок 3 дня,
  далее −8 баллов в день; сдача отчётов, принятие/отклонение с причиной.
- **Справедливое решение**: автоматически при 75 баллах («Лучший») и 140
  («Ведущий»); голосуют куратор должности + владелец; апелляции голосованием
  всех (новичок = 1, остальные = 2), ≥50% — повышение; вторая апелляция —
  гарантированное повышение; кандидаты при занятом месте ведущего.
- **Статистика**: неделя участника, отчёт по проекту, автоанализ владельцу
  (без работ за неделю, оценка <4, задания без движения >3 дней), лучшие/худшие.
- **Напоминания**: всем/нескольким/одному; один раз, еженедельно, по датам;
  одно время для всех или каждому по его часовому поясу.
- **Материалы**: текст, фото, ссылка, файл, видео; видимы всем/только вкладка/
  конкретным участникам; закрепление.
- **Объявления** в чаты объявлений + всем участникам в ЛС.
- **Кураторы**: закрепление за должностью, получают работы своей должности.
- **Место публикации**: группы и темы для заданий/напоминаний/материалов/
  объявлений/чек-листов (добавление через `/id` в чате или `chat_id:тема`).
- **Корзина и архив**: удаления хранятся 48 часов с восстановлением, закрытые —
  в архиве бессрочно.
- **Владелец**: пароли, права каждого админа (тумблеры), выдача ролей 2/3,
  часовые пояса, удаление участника со всеми данными (подтверждение словом
  «УДАЛИТЬ»).
- **Прочее**: поиск участников, логи действий, экспорт CSV (участники/работы/
  логи), баны с синхронизацией с группой, шаблоны, формы, фразы поддержки.

## Команды

- `/start` — вход и главное меню
- `/cancel` — отмена текущего действия
- `/id` — chat_id и тема (отправить из чата, чтобы добавить место публикации)
- `/help` — справка

## Структура

```
main.py            — запуск, роутеры, планировщик
config.py          — токен, пароли, баллы, права
database.py        — SQLite, схема, корзина/архив
services.py        — баллы, справедливое решение, публикация, фоновые задачи
handlers/start.py  — авторизация, меню, профиль, голосования
handlers/tasks.py  — задания, работы, оценивание, шаблоны
handlers/checklists.py, punishments.py, justice.py,
        reminders.py, materials.py, stats.py, admin.py
```

## База данных

Файл `tank_bot.db` создаётся автоматически при первом запуске. Все таблицы
соответствуют спецификации: users, settings, tasks, checklists/
checklist_items/checklist_assignments, works, punishments, votes/vote_records,
trash, archive, materials, reminders, templates, groups, logs, forms.
